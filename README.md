# Acta

A minimalist, offline, and privacy-focused task manager built natively for Android using Jetpack Compose.

Acta is designed to help you organize your daily goals without account sign-ups, analytics, or background internet tracking. Everything stays strictly on your device.

## Features
- **Powerful Subtasks:** Break down complex goals into simple, actionable steps.
- **Privacy First:** 100% offline. Zero trackers, no analytics, no cloud sync, and no unnecessary permissions.
- **Clean & Intuitive:** Designed with Material 3 and Jetpack Compose for a fast, uncluttered experience.
- **Local Backup:** Full control over your data with offline backup and restore.
